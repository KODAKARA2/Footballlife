# 해외 리그 선택 구현과 인수인계

작업 폴더 `/workspace/Footballlife-leagues`, 브랜치 `feature/three-european-leagues`.
최초 기준 `a6d89e5`; 미니게임 공·감독 컷인이 포함된 main `5b89761`을 로컬 fast-forward 병합했습니다. UI 변경은 상단 리그명과 선택 카드 전환 처리이며, 최신 감독 컷인 실행 코드는 보존했습니다. 이미지·이미지 manifest·`js/minigames.js`·원본 Bad0ae는 수정하지 않았습니다. 공개 push/PR/머지/배포는 별도 승인 대기입니다.

## 구단과 선택

`data/mlb/mlb_settings.js`의 `리그` 배열이 단일 원본입니다. 각 리그 5팀, 총 15개 가상 팀입니다. 기존 5개 이름은 유지했습니다.

- EPL: 런던 리버스 FC, 맨체스터 노스 FC, 리버풀 하버 FC, 버밍엄 포지 FC, 브리스톨 윙스 FC
- 라리가: 마드리드 솔 FC, 바르셀로나 마르 FC, 세비야 루스 FC, 발렌시아 아사아르 FC, 빌바오 이사르 FC
- 분데스리가: 도르트문트 발트, 베를린 슈테른 FC, 함부르크 하펜 FC, 뮌헨 모어 FC, 쾰른 브뤼케 FC

진출 제안 수락 → 리그 3개/취소 카드 → 리그 확정 → 해당 5팀 중 무작위 계약입니다. 별도 팀 선택·리그 보너스·난이도·일정 엔진은 없습니다. 해외 현지 이적도 선택한 리그 안에서 배정합니다.

세 진입 카드 `football-mlb_cards-001`, `football-mlb_cards-002`, `football-pro_events-001` 모두 `E.choose`의 공통 처리로 연결됩니다. 리그 확정 전에는 원래 카드/옵션/선택만 `리그선택대기`에 저장하고 경제·나이·턴·계약·플래그 효과는 실행하지 않습니다. 취소는 원래 제안 상태를 복원합니다. `E.next`로 선택을 건너뛸 수 없습니다. UI의 기존 busy 잠금과 엔진의 결과 단계 잠금이 중복 입력을 차단합니다. 자동 저장 및 재로딩도 이 상태를 유지합니다. 해외 진입 계약은 한 번만 체결하며 기존 시즌 정산·보너스·나이 규칙은 유지합니다.

`E.enterStage('해외리그', 'epl' | 'laliga' | 'bundesliga')`는 명시적 리그 인수를 요구합니다. 게임 사용자는 직접 호출하지 않고 선택 카드를 거칩니다. 기존 직접 호출 테스트만 새 계약에 맞게 조정했습니다.

## 기존 저장 마이그레이션

축구 v2 저장 키와 `버전: 2`는 그대로 유지하며 `리그저장버전: 1`을 추가했습니다. 야구 저장에는 접근하지 않습니다.

- `E.load`에서 한 번 적용하는 `E.migrateLeagues`가 현재/마지막 해외 팀, 해외 시즌별 팀, 해외 계약 팀을 기준으로 리그 ID를 보충합니다.
- 기존 런던/맨체스터는 EPL, 마드리드/바르셀로나는 라리가, 도르트문트는 분데스리가로 식별합니다.
- 밀라노 스텔라·파리 뤼미에르·리스본 오세아누는 `legacy`와 표시명 ‘레거시 해외 경력’을 부여합니다. 기존 팀·계약 연봉·재산·나이·기록·관계는 보존합니다. 기존 레거시 해외 경력 내 계약 이동은 이 세 팀의 호환 풀을 사용합니다. 귀국 뒤 새 해외 제안을 수락하면 세 신규 리그 중 다시 선택합니다.
- 과거 해외 시즌은 각 행의 팀으로 판별하므로 현재 리그를 과거 전 경력에 덮어쓰지 않습니다. 이전 순간 기록의 자유 텍스트는 사실을 추정해서 수정하지 않습니다.
- 신규 계약/시즌에는 `리그아이디`, 선수 상태에는 `해외리그아이디`를 저장합니다. 팀은 순수 팀명으로 유지합니다.

상단 소속, 계약/경력 메뉴, 시즌 결산, 해외 팀을 언급하는 이벤트, 진출 순간에 리그를 표시합니다. 기존 커리어 기록 메뉴 함수가 은퇴 진로 함수에 덮이던 문제는 기록 함수를 `U.openRecords`로 분리해 해결했습니다.
